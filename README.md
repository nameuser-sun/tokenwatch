# TokenWatch

DSH（DeepSeek Harness）Token 统计插件

- 状态栏实时预估花费、缓存命中率、输出 token
- GitHub 风格每日消耗热力日历，持久化保存，重启不丢
- 一键预设：智谱 GLM5.3 / DeepSeek / Kimi / Claude / OpenAI GPT
- 自定义高价/经济型模型分组，轻任务自动分流省钱
- 一键清空全部统计数据
- 兼容所有 OpenAI 兼容接口

## 安装

1. 将本插件文件夹推送到 GitHub 仓库（可私有）
2. DSH → 左侧「插件」→ 右上角「+ 添加插件」
3. 主输入框填 GitHub 仓库地址，安装源选 npm 官方源
4. 启用插件，打开插件设置配置模型

## 使用

点击底部状态栏 `📊 TokenWatch` 打开面板

- 加载预设：一键填充价格和模型分组
- 重置数据：清空所有历史日历和会话统计
- 鼠标悬浮热力方块，查看当日总 Token

## 配置异常处理

1. 配置错误、不想继续生效：插件面板一键关闭，立即停止统计与自动分流
2. 面板无法打开：修改插件文件夹名称或删除 `data.json`，重启 DSH 即可隔离
3. 只想保留统计、关闭自动换模型：取消勾选「开启自动轻任务分流」

## 注意事项

- 数据保存在插件目录 `data.json`，备份这个文件即可迁移历史记录
- ⚠️ Claude 原生 Anthropic 接口返回字段不兼容缓存统计，**仅支持 OpenAI 兼容中转**；GPT / GLM / DeepSeek / Kimi 标准兼容接口原生支持缓存统计
- 若使用第三方中转且不返回缓存字段，命中数会显示 0，计费以实际配置为准
